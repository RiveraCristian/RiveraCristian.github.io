## ✨ Características

- 🎨 **Diseño Moderno y Responsivo**: Interfaz elegante que se adapta a todos los dispositivos
- 🌙 **Tema Oscuro/Claro**: Cambio de tema con transiciones suaves
- ⚡ **Animaciones Fluidas**: Implementadas con Framer Motion
- 📱 **Mobile First**: Optimizado para dispositivos móviles, tablets y desktop
- 🎯 **Secciones Interactivas**:
  - Hero con efecto typewriter
  - Timeline de experiencia profesional
  - Showcase de proyectos
  - Formulario de contacto funcional
  - Skills organizados por categorías
- 🚀 **Optimizado para Rendimiento**: Build optimizado con Vite
- ♿ **Accesible**: HTML semántico y aria-labels

## 📦 Instalación y Desarrollo

### Requisitos Previos
- Node.js 18+ 
- npm o yarn

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/RiveraCristian/RiveraCristian.git

# Navegar al directorio
cd RiveraCristian

# Instalar dependencias
npm install
```

### Scripts Disponibles

```bash
# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Preview de build de producción
npm run preview

# Deploy a GitHub Pages
npm run deploy
```
